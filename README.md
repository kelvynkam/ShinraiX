# ShinraiX

Plataforma de streaming de animes desenvolvida para estudos de front-end, JavaScript e arquitetura web.

---

## Sobre o projeto

O ShinraiX é um projeto pessoal inspirado em plataformas de streaming como Netflix e Crunchyroll.

O objetivo é aprender desenvolvimento web na prática, criando um sistema completo de catálogo de animes com:

- Página inicial
- Catálogo de animes
- Sistema de busca
- Favoritos
- Página individual dos animes
- Sistema de episódios
- Responsividade para mobile
- Deploy online com GitHub Pages

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
